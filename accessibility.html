Accessibility Statement

We want every business to be able to request an internet quote here, regardless of how they browse the web.

Our target

This site is built to meet the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA. That standard covers things like color contrast, keyboard operation, text alternatives for images, and clearly labeled form fields.

What we've done

  • Semantic structure with landmark regions and a "skip to content" link as the first focusable element.
  • Every form field has a visible, associated label.
  • The site is fully operable by keyboard, with a visible focus indicator.
  • Text and interface colors are checked against the WCAG AA contrast thresholds.
  • The layout reflows for small screens and respects browser zoom.

Known limitations

We test with automated tooling and manual review, but no site is perfect. If you encounter a barrier, we want to hear about it and will work to fix it.

Report a problem

Email quotes@businessinternetsearch.sdfkjh.com with the page address and a short description of the problem, and we'll respond. If the quote form itself is not usable for you, email us your business name and service address and we'll start the quote that way.
